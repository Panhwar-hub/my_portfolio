# Parvez Ali — Portfolio

Personal research portfolio. Vite + React, no other runtime dependencies.

- **Edit content:** everything lives in `src/data.js`
- **CV:** replace `public/Parvez_Ali_CV.pdf` with your latest CV (same file name)
- **Run locally:** `npm install` then `npm run dev`
- **Publish to GitHub Pages:** `npm run deploy` (builds and pushes `dist/` to the `gh-pages` branch;
  served at https://Panhwar-hub.github.io/my_portfolio/)
